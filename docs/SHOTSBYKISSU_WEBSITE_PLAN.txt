================================================================================
  SECTION 1: PRELOADER / INTRO ANIMATION
================================================================================

  PURPOSE:
  Sets the tone immediately. A short branded loading animation before the
  hero video plays.

  DESIGN:
  - Full-screen overlay, deep black (#1A1A1A) background
  - "SHOTSBYKISSU" text animates in letter by letter in the playful script
    font (Dancing Script), colored hot pink (#FF2D7B)
  - After text completes, it scales up slightly and fades out
  - Overlay slides up to reveal the hero video beneath
  - Total duration: 2-2.5 seconds
  - Only plays on first visit (use sessionStorage to skip on refresh)

  TAILWIND + CUSTOM CSS:
  - Use Tailwind utilities: fixed inset-0 z-[9999] bg-dark flex
    items-center justify-center
  - Custom @keyframes in a <style> block for the letter-by-letter reveal
  - JS to remove overlay from DOM after animation completes

  PLACEHOLDER: None needed — this is pure text animation.

================================================================================
  DESIGN PRINCIPLES
================================================================================

  1. MOBILE FIRST — build for phones, enhance for desktop
  2. PERFORMANCE — compress everything, lazy load, minimal JS libs
  3. ACCESSIBILITY — contrast ratios (pink on white needs care!),
     alt text, keyboard nav, ARIA labels, focus-visible states
  4. CONSISTENCY — Tailwind custom theme enforces spacing/colors/type
  5. WHITESPACE — py-24 minimum padding between sections
  6. CTA VISIBILITY — "Book Now" always in reach (sticky nav + CTAs)
  7. TAILWIND-FIRST — avoid custom CSS unless necessary (keyframes,
     clip-paths, scrollbar-hide). Everything else in Tailwind classes.
